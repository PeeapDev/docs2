# List Transactions

Returns transactions across all wallets owned by your account, newest first.

## Auth

`Authorization: Bearer sk_live_…` (or `sk_test_…`). See [Authentication](/api-reference/auth/api-keys).

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `page` | integer | No | Page number (default 1) |
| `limit` | integer | No | Items per page (default 20, max 100) |

## Example Request

```bash
curl "https://api.peeap.com/v1/transactions?page=1&limit=20" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET_KEY"
```
