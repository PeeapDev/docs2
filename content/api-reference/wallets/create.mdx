# Create Wallet

Create a new wallet for the authenticated user.

## Endpoint

```
POST /wallets
```

## Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Authorization` | Yes | Bearer access token |
| `Content-Type` | Yes | application/json |

## Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `currencyCode` | string | Yes | ISO 4217 currency code. Defaults to `SLE` (Sierra Leonean Leone) — the platform's settlement currency. |

## Example Request

```bash
curl -X POST https://api.peeap.com/wallets \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "currencyCode": "SLE"
  }'
```

## Response

### Success (201 Created)

```json
{
  "id": "wal_abc123",
  "externalId": "wal_1234567890",
  "ownerId": "usr_xyz789",
  "ownerType": "USER",
  "currencyCode": "SLE",
  "availableBalance": 0,
  "heldBalance": 0,
  "status": "ACTIVE",
  "dailyLimit": 5000.00,
  "monthlyLimit": 50000.00,
  "createdAt": "2024-01-15T10:30:00Z"
}
```

### Errors

| Status | Code | Description |
|--------|------|-------------|
| 400 | `INVALID_CURRENCY` | Currency code is not supported |
| 401 | `UNAUTHORIZED` | Invalid or missing access token |
| 409 | `WALLET_EXISTS` | Wallet already exists for this currency |

```json
{
  "statusCode": 409,
  "message": "Wallet already exists for SLE",
  "error": "WALLET_EXISTS"
}
```

## Supported Currencies

| Code | Currency | Notes |
|------|----------|-------|
| `SLE` | Sierra Leonean Leone | **Default.** The canonical settlement currency — all mobile-money top-ups and payouts settle in SLE. |
| `USD` | US Dollar | Available for USD-denominated balances; requires a USD-enabled account. |

<Info>
  Peeap settles in **SLE**. The older `NLE`/`SLL` labels are display aliases only — always send `SLE` as the currency code. `USD` is the only non-Leone currency generally available, subject to account configuration.
</Info>

## Notes

- Users start with default limits based on their KYC tier (tier 0: SLE 1,000 · tier 1: SLE 5,000 · tier 2: SLE 30,000 · tier 3: unlimited)
- Only one wallet per currency is allowed per user
- New wallets have zero balance and are immediately active
