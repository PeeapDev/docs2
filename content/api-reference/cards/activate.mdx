# Activate a Card

Claim a pre-programmed physical or NFC card (from its QR / activation code) and
bind it to the signed-in user's wallet. Activation is race-safe — the first valid
claim wins.

## Auth

**User session** — `Authorization: Bearer <session_token>` (or the
`x-session-token` header / `session_token` cookie).

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `activationCode` | string | Yes | The code from the card QR (`my.peeap.com/activate/{code}`). Case-insensitive. |
| `cardPin` | string | No | 4–6 digits. Sets the account `transaction_pin` **only if one isn't already set**. |

## Example Request

```bash
curl -X POST https://api.peeap.com/cards/activate \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "activationCode": "ABCD-2345", "cardPin": "1234" }'
```

## Success Response (200)

```json
{
  "success": true,
  "message": "Card activated",
  "cardId": "card_9f2c8b1a",
  "nfc_uid": "04A2B3C4D5",
  "walletId": "wal_abc123",
  "pinSet": true,
  "pinAlreadySet": false
}
```

## Errors

| Status | `error` | Meaning |
|--------|---------|---------|
| 401 | `Please log in to activate a card` / `Invalid session` | No/invalid session |
| 400 | `activationCode is required` | Missing code |
| 404 | `Invalid activation code` | Unknown code |
| 400 | `This card has been disabled` | Card blocked |
| 409 | already activated | Includes `mine` (true/false) and `pinAlreadySet` |

<Note>
There are no separate freeze / block / cancel endpoints on the API. Card freeze is
enforced at payment time (`card_frozen`) but is toggled from the Peeap app, not
via a public endpoint.
</Note>
