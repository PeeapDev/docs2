# Plugin Apps

Build micro-apps that run natively inside Peeap. Each app gets its own backend and database, but renders seamlessly inside the platform with full access to wallets, payments, chat, contacts, and notifications.

## How It Works

<Steps>
  <Step title="Build Your App">
    Write a React component that uses the PeeapSDK. Your app has its own Supabase backend for data storage.
  </Step>
  <Step title="Test in Playground">
    Use the SDK playground to test every API call with real data before submitting.
  </Step>
  <Step title="Submit for Review">
    Upload your bundle with a manifest file. Our team reviews it within 48 hours.
  </Step>
  <Step title="Go Live">
    Once approved, your app appears in the Peeap App Store. Users install and use it directly inside the platform.
  </Step>
</Steps>

## Architecture

```
┌──────────────────────────────────────────────────┐
│                  Peeap Platform                   │
│                                                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │ Your App │  │ App B    │  │ App C    │        │
│  │ (React)  │  │ (React)  │  │ (React)  │        │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘        │
│       │              │              │              │
│  ┌────▼──────────────▼──────────────▼────┐        │
│  │           PeeapSDK (scoped)           │        │
│  │  auth | wallet | chat | contacts      │        │
│  │  notifications | platform | storage   │        │
│  └────┬──────────────────────────┬───────┘        │
│       │                          │                 │
│  ┌────▼────────────┐    ┌───────▼────────┐        │
│  │ Peeap Services  │    │  Your Supabase │        │
│  │ (wallets, chat, │    │  (your data)   │        │
│  │  notifications) │    │                │        │
│  └─────────────────┘    └────────────────┘        │
└──────────────────────────────────────────────────┘
```

## Quick Example

```javascript
export default function MyApp({ sdk }) {
  const [user, setUser] = React.useState(null);
  const [wallets, setWallets] = React.useState([]);

  React.useEffect(() => {
    async function load() {
      const u = await sdk.auth.getCurrentUser();
      setUser(u);
      const w = await sdk.wallet.listWallets();
      setWallets(w);
    }
    load();
  }, []);

  if (!user) return <div>Loading...</div>;

  return (
    <div style={{ padding: 20 }}>
      <h1>Hello, {user.firstName}!</h1>
      {wallets.map(w => (
        <div key={w.id}>
          <strong>{w.currency}</strong>: {w.balance.toFixed(2)}
        </div>
      ))}
    </div>
  );
}
```
